A public-safe reference for platform architecture and operations. Its documented local Compose example connects Traefik to a .NET 10 API backed by PostgreSQL across separate edge and data networks. The docs cover delivery, recovery, rollback, and operational evidence. This is a learning demo, not a production deployment.
