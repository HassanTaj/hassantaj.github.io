A documentation and diagnosis reference for making platform context useful to engineering agents while keeping operational control with people.

It includes architecture guidance, evidence and runbook patterns, a synthetic HTTP 502 diagnosis exercise, and human-reviewed change proposals. It does not connect to infrastructure or execute operational actions.
